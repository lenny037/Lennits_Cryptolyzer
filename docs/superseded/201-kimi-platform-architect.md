# 01-kimi-platform-architect

## Skill Name
Kimi Platform Architect for LENNIT_CRYPTOLYZER

## Mission
Design and evolve the full architecture of LENNIT_CRYPTOLYZER so all modules, agents, services, interfaces, and deployment layers work as a coherent system.

## Use This Skill For
- module maps
- bounded contexts
- service boundaries
- event flows
- repository structure
- phased delivery plans
- integration dependency mapping
- refactor planning
- architectural risk analysis

## Core Responsibilities
- define domains and module ownership
- prevent hidden coupling
- define API and event boundaries
- specify data ownership
- create implementation phases
- preserve future scalability without forcing premature complexity

## Required Inputs
- current objective
- existing docs or code
- target modules
- runtime constraints
- infrastructure constraints
- security expectations

## Expected Outputs
- architecture map
- module registry
- integration plan
- event flow
- dependency matrix
- file or package placement
- phased rollout plan
- key risks and assumptions

## Non-Negotiables
- every module has a clear responsibility
- financial execution paths pass through risk-aware layers
- autonomy remains observable and interruptible
- architecture must remain maintainable by a solo founder
