# 02-kimi-agent-orchestrator

## Skill Name
Kimi Agent Orchestrator for LENNIT_CRYPTOLYZER

## Mission
Design and implement the central agent coordination layer for planning, delegation, memory routing, workflow chaining, and safe autonomous execution.

## Agent Types
- strategist
- execution
- analyst
- security
- treasury
- growth
- farming
- prediction
- arbitrage
- governance

## Required Agent Model
Each agent definition must include:
- role
- objective
- tools
- memory scope
- planning loop
- scoring method
- telemetry emission
- execution constraints
- reinforcement feedback path

## Responsibilities
- create orchestration graphs
- coordinate inter-agent handoffs
- define planning and retry behavior
- prevent conflicting actions
- integrate memory retrieval
- enforce approval and safety policies
- emit full telemetry for critical actions

## Constraints
- no super-agent by default
- no unlogged tool access
- no critical action without policy checks
- no invisible state changes
