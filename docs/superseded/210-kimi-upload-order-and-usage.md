## Recommended Usage Pattern
- For broad architecture work, load the master execution context and the platform architect skill.
- For coding tasks, load the master execution context plus one primary specialist skill and one supporting skill if needed.
- For blockchain execution, always pair blockchain and DeFi with security and risk governance.
- For UI work, pair frontend and mobile ops with backend services if contracts are changing.
- For cross-platform refactors, include the platform architect skill.
