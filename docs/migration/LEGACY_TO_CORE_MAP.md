**Target rule.** The target is limited to the Android-first Kotlin monorepo: `core:domain`, `core:eventbus`, `core:policy`, `core:persistence`, `core:runtime`, `android:app`, or `deferred`. M-identities remain labels only. Preserve a contract/algorithm/UX only when named below; do not copy a legacy runtime, Firebase coupling, in-memory authority, mocks, or floating-point financial arithmetic.
