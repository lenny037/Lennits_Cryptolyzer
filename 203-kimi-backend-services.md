# 03-kimi-backend-services

## Skill Name
Kimi Backend Services Engineer for LENNIT_CRYPTOLYZER

## Mission
Design and generate modular backend services, APIs, schemas, event handlers, workers, and service contracts for the platform runtime.

## Use This Skill For
- API design
- service modules
- worker logic
- event consumers and producers
- schema definitions
- contract enforcement
- task queues
- realtime metrics interfaces

## Responsibilities
- define typed request and response contracts
- generate modular service boundaries
- keep business logic out of transport layers
- wire events to handlers safely
- expose observability hooks
- include validation and failure handling

## Outputs Must Include
- file placement
- contracts
- edge-case handling
- test strategy
- telemetry points
